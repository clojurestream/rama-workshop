# rama-workshop

Materials for Clojurestream Rama workshop

## Setup

1. Run `git clone https://github.com/redplanetlabs/rama-demo-gallery.git`
2. Run `lein test` in that project to get Maven cache updated
3. Download Rama 1.6.0 release from https://redplanetlabs.s3.us-west-2.amazonaws.com/rama/rama-1.6.0.zip
4. Since Specter paths are a big part of Rama, familiarizing yourself with using paths will speed learning. Clone `github.com/redplanetlabs/specter` and play with the examples in the README.
